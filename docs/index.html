ClassSnap プライバシーポリシー

最終更新日: 2026年6月9日

ClassSnap（以下「本アプリ」）は、授業中に撮影した板書などの写真を、登録した時間割に基づいて 授業ごとに自動で整理するためのアプリです。本アプリは、利用者のプライバシーを尊重し、 個人情報を慎重に取り扱います。本ポリシーは、本アプリが取り扱う情報とその目的を説明します。

1. 写真へのアクセス

  • 本アプリは、写真を授業ごとに振り分けるために、端末の写真ライブラリへの読み取りアクセスを要求します。
  • 写真の解析・整理・表示は、すべて利用者の端末内でのみ行われます。
  • 写真および写真から得られた情報を、開発者や第三者のサーバーへ送信・アップロードすることは一切ありません。
  • 「アプリ内に保存」機能を有効にした場合、対象の写真は端末内の本アプリ専用領域にコピーされます。このコピーも端末外には送信されません。

2. 端末内に保存される情報

時間割・学期・コマ・補講・テスト範囲などの設定データは、利用者の端末内にのみ保存されます。 本アプリを削除すると、これらのデータはすべて消去されます（写真アプリ内の写真は影響を受けません）。

3. アプリ内課金について

本アプリの有料機能（ClassSnap Pro）の購入には、Apple の App内課金と、購読状態の管理のために RevenueCat, Inc. のサービスを利用します。購入処理および購読状態の確認のため、匿名のアプリ利用者ID および購入情報が RevenueCat を通じて処理されます。氏名・メールアドレスなどの個人を特定する情報を 本アプリが収集することはありません。

  • RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy/
  • Apple のプライバシーポリシー: https://www.apple.com/legal/privacy/

4. 収集しない情報・行わないこと

  • 位置情報・連絡先・氏名などの個人情報の収集は行いません。
  • 広告の表示や、広告目的のトラッキングは行いません。
  • 第三者への情報の販売・提供は行いません。

5. お子様のプライバシー

本アプリは特定の年齢層を対象に個人情報を収集することはありません。

6. 本ポリシーの変更

本ポリシーは、必要に応じて改定されることがあります。重要な変更がある場合は、本ページ上で告知します。
